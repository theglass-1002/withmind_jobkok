  8. 수상 및 자격증: 각종 수상 내역, 자격증
  9. 포트폴리오/문서 업로드: PDF, 이미지 등

5. API 연동

5.1 REST API 구조

5.1.1 기본 설정

항목 내용
Base URL https://api.jobkok.kr
AI Base URL https://ai.api.jobkok.kr
인증 방식 Bearer Token (JWT)
인증 헤더 Authorization: Bearer {accessToken}

5.1.2 토큰 관리

  • Access Token: API 요청 인증
  • Refresh Token: Access Token 갱신
  • 자동 갱신: 401/403 에러 시 자동 refresh
  • 저장소: LocalStorage / SessionStorage

5.2 주요 API 엔드포인트

5.2.1 인증 API (/api/auth/)

메서드 엔드포인트 설명
POST /auth/login 로그인
POST /auth/signup 회원가입
POST /auth/refresh 토큰 갱신
POST /auth/logout 로그아웃
GET /auth/oauth/kakao 카카오 로그인
GET /auth/oauth/naver 네이버 로그인
GET /auth/oauth/google 구글 로그인

5.2.2 이력서 API (/api/resume/)

메서드 엔드포인트 설명
GET /resume 이력서 목록
POST /resume 이력서 생성
GET /resume/:id 이력서 상세
PUT /resume/:id 이력서 수정
DELETE /resume/:id 이력서 삭제

5.2.3 채용공고 API (/api/job/)

메서드 엔드포인트 설명
GET /job 공고 목록
GET /job/:id 공고 상세
POST /job/bookmark 북마크 추가
DELETE /job/bookmark/:id 북마크 삭제

5.2.4 모의면접 API (/api/interview/)

메서드 엔드포인트 설명
POST /interview/start 면접 시작
POST /interview/answer 답변 제출
POST /interview/end 면접 종료
GET /interview/:id 면접 상세

5.3 API 응답 형식

5.3.1 성공 응답

{
  "code": 200,
  "msg": "SUCCESS",
  "data": { ... }
}

5.3.2 에러 응답

{
  "code": 400,
  "msg": "ERROR_MESSAGE"
}

5.4 에러 처리

에러 코드 처리 방법
401 Unauthorized 토큰 만료 → 자동 Refresh Token 갱신
403 Forbidden 권한 없음 → 로그인 페이지 리다이렉트
503 Service Unavailable 점검 중 → ComingSoon 페이지
999 Custom Error NO_TOKEN, TOKEN_REFRESH_FAILED

5.5 이벤트 추적 시스템

Axios 인터셉터를 통한 자동 이벤트 수집:

  • API 호출 추적: 모든 API 요청/응답 시간 기록
  • 클릭 이벤트: 버튼, 링크 클릭 추적
  • 페이지 뷰: 페이지 전환 추적
  • 에러 추적: JS 에러, API 에러 자동 수집
  • 배치 전송: 10초마다 또는 페이지 이탈 시 전송

9. 개발 중 이슈 및 해결 방법

9.1 토큰 갱신 무한 루프 문제

문제: 401 에러 발생 시 Refresh Token 갱신 시도하면서 무한 루프 발생
해결: _retry 플래그로 재시도 1회 제한 
if (!originalRequest._retry) {
  originalRequest._retry = true;
  // Refresh Token 갱신 로직
}

9.2 소셜 로그인 리다이렉트 처리

문제: 카카오/네이버/구글 OAuth 콜백 URL 처리 및 토큰 추출
해결: 콜백 URL을 Login 컴포넌트로 라우팅하고 URL 파라미터에서 토큰 추출

9.3 이력서 파일 업로드 크기 제한

문제: 대용량 파일 업로드 시 서버 에러
해결:
  • 클라이언트에서 사전 검증 (5MB 이하)
  • 파일 크기 초과 시 Toast 알림
  • 이미지 압축 처리

9.4 모바일 환경에서 마이크 권한

문제: 모바일 브라우저에서 마이크 권한 요청 실패 (HTTPS 필수)
해결:
  • Firebase Hosting으로 HTTPS 배포
  • 권한 요청 전 사용자 안내 모달 표시

9.5 페이지 새로고침 시 404 에러

문제: SPA 라우팅에서 새로고침 시 404 발생
해결: Firebase 호스팅 설정에서 모든 경로를 index.html로 리다이렉트 
{
  "hosting": {
    "rewrites": [
      { "source": "**", "destination": "/index.html" }
    ]
  }
}

9.6 점검 모드 처리

문제: 서버 점검 시 사용자 안내 필요
해결:
  • API에서 503 상태 코드 반환
  • Axios 인터셉터에서 자동 감지
  • ComingSoon 페이지로 리다이렉트

9.7 기업/사용자 이중 인증 시스템

문제: 일반 회원과 기업 회원의 토큰 분리 필요
해결:
  • 토큰 타입 구분 (tokenType: "user" | "company")
  • LocalStorage에 별도 키로 저장
  • API 요청 시 동적으로 토큰 선택
